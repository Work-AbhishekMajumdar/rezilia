The problem

Three walls every Node.js backend hits

These aren't edge cases — they're production failures waiting to happen. rezilia solves all three with zero config defaults.

Cache Stampede
When cache expires, 1,000 requests simultaneously hit the database. The DB can't cope. Everything goes down.
SmartCache
Singleflight pattern — only 1 fetcher runs. All concurrent callers wait and share the same result. DB sees exactly 1 query.
Lost Log Context
Request ID disappears across async/await. You can't trace a request through your logs. Debugging is guesswork.
SmartLogger
AsyncLocalStorage propagates requestId automatically through the entire async call chain — no manual passing required.
Cascading Failures
One slow external API stalls your thread pool. Retries hammer an already-failing service. Everything cascades.
SmartRetry
Circuit breaker stops calling a failing service. Exponential backoff with jitter prevents thundering herd on recovery.

SmartCache

Singleflight + Stale-While-Revalidate + TTL jitter — the #1 missing primitive in the JS ecosystem.

cache-example.ts
import { SmartCache } from 'rezilia/cache';

const cache = new SmartCache({
  defaultTtl: 60_000,           // 1 minute
  jitterFactor: 0.1,            // ±10% TTL — prevents mass expiry
  staleWhileRevalidate: true,   // serve stale instantly while refreshing
  staleTtl: 5_000,
});

// 100 concurrent callers → fetcher runs exactly ONCE
const results = await Promise.all(
  Array.from({ length: 100 }, () => cache.get('user:42', () => db.findUser(42)))
);
// db.findUser called: 1 time ✓

// Redis store (optional — npm install ioredis)
import { RedisStore } from 'rezilia/cache';
import Redis from 'ioredis';
const redisCache = new SmartCache({ store: new RedisStore(new Redis()) });

SmartLogger

Structured JSON logs with automatic requestId propagation through every async boundary. Auto-redacts secrets.

logger-example.ts
import { SmartLogger, requestLogger } from 'rezilia/logger';

const logger = new SmartLogger({ serviceName: 'api', level: 'info' });

// requestId flows automatically — no manual passing
logger.runWithContext({ requestId: req.id }, async () => {
  logger.info('Processing payment');  // → requestId included ✓
  await processPayment();
  logger.info('Payment done');        // → requestId still here ✓
});

// Auto-redaction — password never leaks
logger.info('Login', { username: 'alice', password: 'secret' });
// → {"data":{"username":"alice","password":"[REDACTED]"}}

app.use(requestLogger(logger)); // Express middleware

SmartRetry

Exponential backoff with jitter, per-attempt timeouts, and an integrated circuit breaker.

CLOSED
Requests flow normally
5 failures
OPEN
Fail fast — no upstream calls
30s timeout
HALF
OPEN
Probe with limited requests
2 successes
CLOSED
Fully recovered
retry-example.ts
import { SmartRetry, retry } from 'rezilia/retry';

// One-liner
const data = await retry(() => api.getData(), { attempts: 3, baseDelay: 500 });

// Full control with circuit breaker
const retrier = new SmartRetry({
  attempts: 5,
  baseDelay: 500,     // 500 → 1000 → 2000 → 4000ms
  maxDelay: 30_000,
  jitter: 0.2,        // ±20% — prevents thundering herd
  timeout: 10_000,    // per-attempt timeout
  circuitBreaker: { threshold: 5, resetAfter: 30_000, halfOpenSuccesses: 2 },
});

const result = await retrier.execute(() => paymentGateway.charge(order));
console.log(retrier.circuitState); // 'CLOSED' | 'OPEN' | 'HALF_OPEN'
