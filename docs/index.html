💡 What rezilia Solves (In Detail)

Modern distributed backends inevitably face three fatal architectural failures under load. Here is how rezilia completely eliminates each one:

📦 1. Cache Stampede & Thundering Herd Problem
Failure Mode SmartCache Solution
High-traffic backends fail when hot cached items (e.g., user:profile or feed:home) expire during peak traffic. If 1,000 requests arrive concurrently at that millisecond, naive backends run 1,000 separate database queries at once.
✕ Without rezilia

Database Exhaustion: 1,000 queries flood the connection pool simultaneously. CPU hits 100%, read latency spikes from 3ms to 8,000ms, and un-indexed DB queries trigger timeouts or full crashes.

✓ With rezilia (Singleflight + SWR)

Single in-flight Promise: Exactly 1 database fetch executes. The other 999 callers await the same in-memory mutex. With SWR, stale data returns in 0ms while refreshing in the background, and TTL Jitter (±10%) prevents mass synchronized expiry.

📝 2. Lost Log Context & Uncorrelated Production Debugging
Failure Mode SmartLogger Solution
In Node.js's event-loop model, the instant code awaits an external HTTP call or database promise, the original execution context disconnects. Correlating logs across multi-tenant requests becomes nearly impossible.
✕ Without rezilia

Debugging Nightmare: Developers must manually thread requestId, userId, and tenantId as arguments through dozens of service functions. One forgotten parameter breaks the log chain, leaving disjointed production logs.

✓ With rezilia (AsyncLocalStorage)

Zero-Parameter Propagation: Context initialized once at the middleware boundary automatically flows across every nested async call, promise, and timer. Plus, Automatic Secret Redaction scrubs API keys, auth tokens, and passwords before writing JSON.

🔄 3. Cascading Microservice Outages & Retry Storms
Failure Mode SmartRetry Solution
When a downstream third-party partner (e.g. payment processor, shipping API) degrades or hangs, calling services keep dispatching requests and immediate retries, causing thread and socket exhaustion.
✕ Without rezilia

Cascading Outages: Hundreds of concurrent requests hang waiting for unresponsive downstreams, depleting HTTP sockets and event loop capacity until your entire microservice mesh collapses with 504 Gateway Timeouts.

✓ With rezilia (Circuit Breaker)

0ms Fast-Fail Isolation: After consecutive errors reach threshold, the breaker trips to OPEN, rejecting callers immediately in 0ms so the downstream service can recover. Exponential Backoff + Jitter (±20%) prevents synchronized retry spikes.

🚀 Installation

rezilia works seamlessly across all modern Node.js and Bun package managers:

npm install rezilia

Quick Start

import { SmartCache, SmartLogger, retry } from 'rezilia';

// 1. Cache: 1000 concurrent calls collapse into exactly 1 database fetch
const cache = new SmartCache({ defaultTtl: 60_000 });
const user = await cache.get('user:42', () => db.findUser(42));

// 2. Logger: Context & requestId auto-propagate across all async boundaries
const logger = new SmartLogger({ serviceName: 'payment-service' });
logger.runWithContext({ requestId: req.id }, async () => {
  logger.info('Processing transaction'); // contains requestId automatically!
});

// 3. Retry: Exponential backoff + Circuit breaker protection
const data = await retry(() => paymentGateway.charge(order), {
  attempts: 4,
  timeout: 5_000,
  circuitBreaker: { threshold: 5, resetAfter: 30_000 }
});

SmartRetry Options Reference

Attribute Type Default Allowed Values / Range Description
attempts number 3 1 to 20 Maximum total execution attempts (initial try + retries) before throwing error.
baseDelay number (ms) 500 50 to 10000 Initial wait time before the first retry attempt.
maxDelay number (ms) 30000 1000 to 120000 Ceiling limit for exponential backoff delay to avoid infinite stalls.
jitter number 0.2 0.0 (0%) to 1.0 (100%) Randomized delay variance (+/- percentage) preventing synchronized thundering herds.
timeout number (ms) 10000 0 (disabled) or > 0 Per-attempt execution timeout. If an attempt hangs, it is aborted and retried.
circuitBreaker object undefined { threshold, resetAfter, halfOpenSuccesses } Configuration object enabling the stateful Circuit Breaker.
shouldRetry (err: Error) => boolean () => true Custom predicate function Inspects errors to skip retries on 4xx client issues and only retry on 5xx/network errors.

SmartCache Options Reference

Attribute Type Default Allowed Values / Range Description
defaultTtl number (ms) 60000 (1m) 1000 to 86400000 Default expiration lifetime for stored cache items.
jitterFactor number 0.1 (10%) 0.0 to 0.5 Applies +/- randomness to TTL to prevent simultaneous mass cache eviction.
staleWhileRevalidate boolean false true | false If enabled, serves expired data immediately while fetching fresh data in the background.

3. 📝 SmartLogger & Context Propagation

Zero-overhead structured JSON logger powered by Node.js AsyncLocalStorage. Auto-redacts sensitive secrets and carries correlation IDs across async boundaries.

import { SmartLogger } from 'rezilia/logger';

const logger = new SmartLogger({ serviceName: 'billing-api' });

// Context flows automatically into every nested function call
logger.runWithContext({ requestId: 'req_981a', userId: 'usr_42' }, async () => {
  logger.info('Initiating payment');
  await chargeCustomer();
  logger.info('Charge complete'); 
});

// Automatic Secret Redaction
logger.info('User auth', { apiKey: 'sk_live_990182', password: 'hunter2' });
// Output: { "apiKey": "[REDACTED]", "password": "[REDACTED]" }

SmartLogger Options Reference

Attribute Type Default Allowed Values Description
serviceName string Required e.g. 'order-api' Service name injected into every emitted JSON log record.
minLevel string 'info' 'debug' | 'info' | 'warn' | 'error' | 'silent' Minimum threshold required for a log message to be output.
redactKeys string[] [password, token, apiKey, secret, authorization, ...] Array of keys List of sensitive key names that are automatically replaced with "[REDACTED]".

🌳 Tree-Shakeable Imports

rezilia is engineered for minimal bundle footprint. You can import only the specific sub-modules your service requires:

import { SmartCache }  from 'rezilia/cache';   // Cache only
import { SmartLogger } from 'rezilia/logger';  // Logger only
import { retry }       from 'rezilia/retry';   // Retry only
import { SmartCache, SmartLogger, retry } from 'rezilia'; // All utilities

// CommonJS is fully supported
const { SmartCache } = require('rezilia/cache');
