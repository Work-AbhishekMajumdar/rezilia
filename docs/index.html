rezilia

Zero-dependency Node.js resilience toolkit for production backends.

GitHub npm Get started →

Introduction

rezilia packages three production-hardened resilience patterns into a single zero-dependency TypeScript library. If you've ever been paged because a cache key expired at the wrong moment, lost a requestId somewhere deep in an async chain, or watched your service hammer a dead dependency — this is the toolkit for you.

Features

🛡️
Cache stampede prevention
Singleflight ensures only 1 fetcher runs per key. 1,000 concurrent callers share one result.
📝
Async context logging
AsyncLocalStorage propagates requestId through every async hop — zero manual passing.
⚡
Circuit breaker
Opens after N failures, half-opens to probe recovery. Fail-fast protects downstream services.
📦
Zero dependencies
No runtime deps. Full TypeScript. ESM + CJS + Bun support out of the box.

Modules

rezilia ships three independent modules. Import only what you need:

ts
// Cache stampede prevention
import { SmartCache } from 'rezilia/cache';

// Structured async logging
import { SmartLogger } from 'rezilia/logger';

// Circuit breaker + retry
import { SmartRetry } from 'rezilia/retry';

// Or everything at once
import { SmartCache, SmartLogger, SmartRetry } from 'rezilia';

SmartCache

Singleflight + stale-while-revalidate + TTL jitter. No DB meltdowns.

The problem

A cache key expires during a traffic spike. Every in-flight request sees a miss and fires a database query simultaneously. This is a cache stampede (thundering herd). With a 2.8-second query and 1,000 concurrent requests — your DB chokes.

⚠ What happens without singleflight
Cache expires → 1,000 requests miss → 1,000 DB queries fire → DB chokes → timeouts cascade → incident.

Singleflight

When a key is being fetched, all subsequent callers for that key wait and share the single result. Only one fetcher runs per key, no matter how many callers arrive.

ts
import { SmartCache } from 'rezilia/cache';

const cache = new SmartCache({ defaultTtl: 60_000 });

// 1,000 concurrent calls → fetcher runs exactly ONCE
const results = await Promise.all(
  Array.from({ length: 1000 }, () =>
    cache.get('user:42', () => db.findUser(42))
  )
);
// All 1,000 get the same result. DB query ran once.

Stale-while-revalidate

Serve the stale cached value instantly while refreshing in the background. Users never see a slow response during revalidation.

ts
const cache = new SmartCache({
  defaultTtl: 60_000,
  staleWhileRevalidate: true,   // serve stale, refresh async
  jitterFactor: 0.1,             // ±10% TTL randomness
});

const user = await cache.get('user:42', () => db.findUser(42));
// Returns stale value in <1ms. Refresh happens in background.

TTL jitter

Without jitter, all keys set at the same time expire at the same time — causing a mass simultaneous expiry spike. jitterFactor adds randomness to spread expiration across a window.

ts
// TTL of 60s with 10% jitter → actual TTL: 54s–66s
const cache = new SmartCache({
  defaultTtl: 60_000,
  jitterFactor: 0.1,
});

// Per-key TTL override
await cache.set('session:xyz', data, 300_000);

// Delete a key
cache.del('user:42');

// Clear everything
cache.clear();

SmartLogger

AsyncLocalStorage-based structured logging with automatic context propagation.

The problem

You attach a requestId in Express middleware. You log it once. Then you call an async helper — and it's gone. You end up threading it through every function signature.

ts
// Without SmartLogger — requestId must be passed everywhere
function handleRequest(req, res) {
  doThing(req.id);
}
function doThing(requestId) {
  doNestedThing(requestId); // pass it again
}
function doNestedThing(requestId) {
  logger.info('...', { requestId }); // still passing
}

Request context

SmartLogger uses Node's AsyncLocalStorage to bind a context to the current async execution tree. Any function called within the context — regardless of nesting depth — automatically sees it.

ts
import { SmartLogger, requestLogger } from 'rezilia/logger';

const logger = new SmartLogger({ serviceName: 'api' });

// Middleware automatically injects requestId
app.use(requestLogger(logger));

app.get('/users/:id', async (req, res) => {
  logger.info('Fetching user'); // ✓ requestId here automatically
  const user = await db.getUser(req.params.id);
  logger.info('User fetched');  // ✓ still here through all async hops
  res.json(user);
});

Auto-redaction

SmartLogger automatically redacts sensitive fields before they reach your log sink. No accidental leakage of tokens, passwords, or card numbers.

ts
// Redacted by default: password, token, apiKey, cardNumber, secret, authorization
logger.info('Auth attempt', {
  user: 'alice',
  password: 'hunter2',   // → "[REDACTED]"
  token: 'sk-abc123',    // → "[REDACTED]"
});

// Add custom redacted fields
const logger = new SmartLogger({
  serviceName: 'payments',
  redactedFields: ['ssn', 'accountNumber'],
});

SmartRetry

Exponential backoff with jitter and an integrated circuit breaker state machine.

Circuit breaker

The circuit breaker prevents your service from hammering a dependency that's already down. It transitions through three states:

CLOSED
Normal
N failures
→
OPEN
Fail fast
timeout
→
HALF
OPEN
Probe
success
→
CLOSED
Recovered
ts
import { SmartRetry } from 'rezilia/retry';

const retrier = new SmartRetry({
  attempts: 5,
  baseDelay: 500,   // doubles: 500 → 1000 → 2000 → 4000ms
  jitter: 0.2,      // prevents synchronized retries across instances
  timeout: 10_000, // per-attempt timeout

  circuitBreaker: {
    threshold: 5,          // open after 5 consecutive failures
    resetAfter: 30_000,   // probe after 30s
    halfOpenSuccesses: 2,  // need 2 successes to close again
  },
});

const result = await retrier.execute(() => paymentGateway.charge(order));
// Fails fast when OPEN — no waiting on dead service

Exponential backoff

Each retry waits longer than the last, with jitter to prevent synchronized thundering herds from multiple service instances all retrying at the same moment.

ts
// Retry delays with baseDelay: 500, jitter: 0.2
// Attempt 1: ~500ms ± 20%  → 400–600ms
// Attempt 2: ~1000ms ± 20% → 800–1200ms
// Attempt 3: ~2000ms ± 20% → 1600–2400ms
// Attempt 4: ~4000ms ± 20% → 3200–4800ms

const retrier = new SmartRetry({
  attempts: 4,
  baseDelay: 500,
  jitter: 0.2,
  // Optional: custom retry condition
  retryOn: (err) => err.statusCode >= 500,
});

Quick start

Get all three modules working in under 5 minutes.

1. Install

bash
npm install rezilia

2. Prevent cache stampedes

ts
import { SmartCache } from 'rezilia/cache';

const cache = new SmartCache({
  defaultTtl: 60_000,
  staleWhileRevalidate: true,
  jitterFactor: 0.1,
});

// In your route handler:
const user = await cache.get(`user:${req.params.id}`, () =>
  db.findUser(req.params.id)
);

3. Add request context logging

ts
import { SmartLogger, requestLogger } from 'rezilia/logger';
import express from 'express';

const app = express();
const logger = new SmartLogger({ serviceName: 'api' });
app.use(requestLogger(logger)); // requestId in every log automatically

app.get('/users/:id', async (req, res) => {
  logger.info('Fetching user'); // includes requestId automatically
  const user = await db.getUser(req.params.id);
  res.json(user);
});

4. Add circuit breaker for external calls

ts
import { SmartRetry } from 'rezilia/retry';

const retrier = new SmartRetry({
  attempts: 5,
  baseDelay: 500,
  jitter: 0.2,
  circuitBreaker: { threshold: 5, resetAfter: 30_000 },
});

// Wrap any external call:
const result = await retrier.execute(() => stripe.charges.create(params));

API Reference

Full API surface for all three modules.

SmartCache

Constructor

ts
new SmartCache(options: {
  defaultTtl: number;              // ms — required
  staleWhileRevalidate?: boolean;  // default: false
  jitterFactor?: number;           // 0–1, default: 0
  maxSize?: number;                 // max entries, default: unlimited
})

Methods

MethodDescription
get(key, fetcher, ttl?)Get from cache. Runs fetcher on miss (singleflight).
set(key, value, ttl?)Set a value directly.
del(key)Delete a key.
has(key)Check if key exists and is fresh.
clear()Remove all entries.
size()Current number of entries.

SmartLogger

Constructor

ts
new SmartLogger(options: {
  serviceName: string;
  level?: 'debug' | 'info' | 'warn' | 'error';  // default: 'info'
  redactedFields?: string[];  // merged with defaults
  output?: (line: string) => void;  // default: process.stdout
})

Methods

MethodDescription
debug(msg, meta?)Debug-level structured log.
info(msg, meta?)Info-level structured log.
warn(msg, meta?)Warning-level structured log.
error(msg, meta?)Error-level structured log.
runWithContext(ctx, fn)Run fn with context bound to async scope.

SmartRetry

Constructor

ts
new SmartRetry(options: {
  attempts: number;
  baseDelay?: number;     // ms, default: 1000
  maxDelay?: number;      // ms cap, default: 30000
  jitter?: number;        // 0–1, default: 0.1
  timeout?: number;       // per-attempt ms, default: none
  retryOn?: (err: Error) => boolean;
  circuitBreaker?: {
    threshold: number;
    resetAfter: number;   // ms
    halfOpenSuccesses?: number;  // default: 1
  };
})

Methods

MethodDescription
execute(fn)Run fn with retry + circuit breaker logic.
getState()Returns 'CLOSED' | 'OPEN' | 'HALF_OPEN'.
reset()Manually reset the circuit breaker to CLOSED.
